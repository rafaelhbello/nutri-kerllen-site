# Configuração do Supabase para Anamnese

Para que o formulário de anamnese funcione corretamente, siga estes passos no seu painel do Supabase:

## 1. SQL Editor (Reparo de Tabela e RLS)
Vá em **SQL Editor** > **New Query**, cole o código abaixo e clique em **Run**:

```sql
-- Garantir que a tabela existe
create table if not exists public.anamneses (
  id          bigint generated by default as identity primary key,
  nome        text,
  telefone    text,
  sexo        text,
  idade       int,
  respostas   jsonb,
  treinos     jsonb,
  created_at  timestamptz default now()
);

-- Habilitar RLS
alter table public.anamneses enable row level security;

-- Criar política para inserção pública (Anônima)
drop policy if exists "public insere anamneses" on public.anamneses;
create policy "public insere anamneses"
on public.anamneses
for insert
to anon
with check (true);

-- Garantir permissões para a role anon
grant insert on public.anamneses to anon;
grant usage on sequence public.anamneses_id_seq to anon;
```

## 2. API Key (Anon Key)
1. Vá em **Project Settings** > **API**.
2. Copie a chave **anon public**.
3. Abra o arquivo `js/supabase.js` no seu código.
4. Substitua o valor da variável `SUPABASE_KEY` pela chave que você copiou.

## 3. Verificação de Erros
Se o erro persistir, abra o **Console do Desenvolvedor** (F12) no seu navegador ao tentar enviar. Eu adicionei um log detalhado chamado `ERRO SUPABASE DETALHADO` que mostrará exatamente o motivo da falha.
